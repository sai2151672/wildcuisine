# Alex's Cuisine

A Fabric mod that adds cuisine between **Alex's Mobs** and **Farmer's Delight** for Minecraft 1.20.1.

All textures, item names, and recipe compositions are original creations for this mod.

## Features

- **Raw meats** harvested from Alex's Mobs creatures (Bison, Bunfungus, Centipede Leg, Catfish) via loot table integration
- **Cuts & prep** using the Farmer's Delight cutting board (shanks, ribs, mince, patties, drumsticks, fish slices)
- **Cooking** with the FD cooking pot: Kangaroo Stew, Acacia Blossom Soup, Lobster Pasta, Kangaroo Pasta
- **Crafting** meals: Bison Burger, Bunfungus Sandwich, Gongylidia Bruschetta, Maggot Salad, Barbecue on a Stick
- **Smelting / smoking / campfire** variants for every raw ingredient

## Dependencies

- Fabric API
- Alex's Mobs (Fabric, 1.20.1)
- Farmer's Delight Refabricated

## Build

- JDK 17
- Gradle 8.7 (Fabric Loom 1.6-SNAPSHOT)

```sh
./gradlew build
```

Output jar is at `build/libs/alexscuisine-1.0.0.jar`.
